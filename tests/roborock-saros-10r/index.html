Roborock Saros 10R : notre avis complet

Publié le 9 septembre 2026 Note : 9,1/10 Catégorie : robot aspirateur haut de gamme

Pas le robot aux chiffres les plus impressionnants sur le papier, mais son équilibre général est excellent — et sa navigation est probablement la meilleure de la gamme.

Points forts

  • Navigation exceptionnelle
  • Très bonne aspiration
  • Excellent passage sous les meubles
  • Très bonne détection des obstacles
  • Excellent choix pour les animaux

Points faibles

  • Nettoyage des tapis perfectible sur certaines saletés
  • Performances de lavage pas toujours au niveau des modèles les plus récents

Le Saros 10R reste l'un des robots les plus intéressants de la gamme pour les utilisateurs qui privilégient la navigation et l'autonomie.

Il n'est pas forcément le robot affichant les chiffres les plus impressionnants sur le papier, mais son équilibre général est excellent.

Aspiration 8,8/10

Les performances sont particulièrement bonnes sur les sols durs. Les tests indépendants le classent parmi les robots très performants pour récupérer les saletés quotidiennes.

Sur certains tapis, les particules très fines situées dans les fibres peuvent toutefois demander plusieurs passages.

Navigation 9,5/10

C'est probablement son principal avantage.

Le Saros 10R est particulièrement performant pour identifier les objets présents au sol. Il est notamment réputé pour éviter efficacement les obstacles et les déjections d'animaux.

C'est un vrai avantage dans une maison où le sol n'est pas toujours parfaitement dégagé.

Passage sous les meubles 9,5/10

Avec son système LiDAR rétractable, le robot peut réduire sa hauteur et accéder à des espaces particulièrement bas.

C'est un argument important face aux anciens robots équipés d'une tourelle LiDAR fixe.

Lavage 8,8/10

Le système de lavage est très efficace pour l'entretien courant. Il est toutefois possible de trouver plus performant sur les taches particulièrement incrustées.
